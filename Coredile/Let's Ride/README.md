# Let's Ride

Tourists post a trip, verified local drivers bid, the tourist picks. No booking fee, no commission. Brand: letsride.lk.
Mint road `#05F0B3` on deep green, Manrope type.

```
Source code/
  backend/    Laravel API                      GitHub: Let-s-Ride/backend
  frontend/   React web app                    GitHub: Let-s-Ride/frontend
  admin/      Admin panel (Vite)               GitHub: Let-s-Ride/admin
  landing/    letsride.lk website (Astro)      GitHub: Let-s-Ride/landing   (news/ and guides/ hold articles)
  mobile/     Flutter app                      GitHub: Let-s-Ride/mobile
Brand/        logo.png, app_icon.png, newlogo/ (black and white logos and icons)
Design drafts/ Old landing page redesigns and the dark-mode mobile design (reference only)
Video studio/ Remotion project for videos and banners (see its README). Not in git yet.
Social Media Marketing/
  Videos/     Finished MP4s: "How it works" wide + tall
  Banners/    Finished square banner (1080x1080)
```

## Support and social (where the work comes from)

Channels: Facebook, YouTube, Instagram, TikTok. Support: official WhatsApp and in-app chat.
Daily jobs: answer queries, review new vehicle registrations, post videos, publish articles to the website.
The automation plan is in the project notes; nothing customer-facing is sent without approval.

## Making things

- Video or banner: `Video studio/README.md`. Banner source: `Video studio/src/banners/SquareBanner.tsx`.
- Website article: add a file to `Source code/landing/src/content/news` (or `guides`), review, merge.
- Flutter paths are generated: after the move run `flutter pub get` in `Source code/mobile` once.
