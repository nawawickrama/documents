# Coredile POS

Multi-industry, offline-first POS and business platform (Laravel API, React apps, Electron till for Windows).
Live site: coredilepos.cloud.

```
Source code/   The POS repository.            GitHub: Coredile-com/pos. READ its CLAUDE.md and docs/ first.
Website/       coredilepos.cloud (Astro). Not in git yet.
Video studio/  Remotion project for the promo videos. Not in git yet.
Videos/        Finished MP4s, wide + tall
Product guides/ Bakery, Restaurant and Shop guides (PDF)
Sales presentations/ General (English, Sinhala), Restaurant, Bakery, Shop (.pptx)
Social posts/  Caption text for each video
Screenshots/   Working screenshots from 30 Sep 2026
```

Rules: finished files only in `Videos`, `Product guides`, `Sales presentations`, `Social posts`.
The website is kept apart from the POS repo so a website change never redeploys the POS.
